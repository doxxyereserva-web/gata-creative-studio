# Ágata Creative Studio

Não, melhor, Ágata (variação do qurtzo) só Ágata. 
Utilize esse prompt pra construir a plataforma. 
PROJECT: ÁGATA
TYPE: Premium Roblox Development Platform
DESIGN DIRECTION: Apple-inspired, Liquid Glass, Minimalist Luxury.
I want you to design and build an exceptionally polished, premium website for a platform called Ágata.
Ágata is a platform dedicated to Roblox development, bringing together:
- Scripts and systems.
- Visual effects (VFX).
- 3D models and assets.
- Development resources.
- Creative tools and components.
IMPORTANT:
This must NOT look like a generic SaaS website, a typical marketplace template, or an AI-generated landing page.
The design must feel like something developed by a world-class design agency with a $10,000+ budget.
Think Apple-level attention to detail.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
01. DESIGN PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The visual identity should combine:
- Apple's premium design philosophy.
- Liquid Glass materials.
- Sophisticated minimalism.
- Beautiful typography.
- Carefully controlled whitespace.
- Subtle depth and dimensionality.
- Elegant animations and transitions.
The website should feel expensive without trying too hard.
Avoid excessive gradients, unnecessary decorations, generic cards, oversized icons, and visual clutter.
Every element must have a reason to exist.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
02. COLOR SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Create two complete visual themes.
LIGHT MODE:
- Primary background: pure white (#FFFFFF).
- Secondary surfaces: subtle off-white.
- Text: near-black.
- Borders: extremely subtle neutral gray.
- Glass surfaces: translucent white with sophisticated backdrop blur.
DARK MODE:
- Primary background: deep black (#080808).
- Secondary surfaces: dark charcoal.
- Text: soft white.
- Borders: subtle dark gray.
- Glass surfaces: translucent black with controlled reflections.
The transition between themes must be beautiful and instantaneous-feeling.
Add a theme toggle with a refined animation.
Remember:
The dark theme should feel like Apple's dark interfaces, not a generic dashboard with a black background.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
03. LIQUID GLASS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Implement Liquid Glass-inspired components.
Use:
- Translucent navigation surfaces.
- Sophisticated backdrop blur.
- Subtle highlights and reflections.
- Delicate borders.
- Layered transparency.
- Natural shadows.
- Carefully controlled depth.
Glass must feel physical and refined.
Do NOT apply glass effects to everything.
Use it strategically for:
- Navigation.
- Floating controls.
- Selected interactive elements.
- Important overlays.
- Small contextual panels.
The result should resemble a premium operating system interface.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
04. TYPOGRAPHY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Typography is extremely important.
Use a sophisticated modern sans-serif font.
Preferred options:
- Inter.
- Geist.
- SF Pro-inspired typography.
Use precise typography hierarchy.
Headlines should be confident, elegant and memorable.
Body text should be comfortable to read.
Avoid generic marketing phrases and unnecessary text.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
05. NAVIGATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Create a beautiful floating navigation bar.
It should include:
ÁGATA logo and wordmark.
Navigation:
- Discover
- Scripts
- VFX
- 3D Models
- Resources
Right side:
- Search.
- Theme toggle.
- User profile / Sign in.
The navigation should use a subtle Liquid Glass surface.
On scroll, it should remain elegant and compact.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
06. HERO SECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The hero must immediately communicate the quality and identity of Ágata.
Create a visually impressive composition.
Suggested headline:
"Create beyond limits."
Supporting text:
"Everything you need to build extraordinary experiences on Roblox."
Primary CTA:
"Explore Ágata"
Secondary CTA:
"Discover resources"
The hero should have an exceptional visual composition.
Explore subtle 3D-inspired elements, elegant lighting, abstract material surfaces and sophisticated visual details.
The visual identity should subtly reference the natural mineral Ágata (Agate).
Consider using:
- Mineral-inspired textures.
- Layered translucent structures.
- Delicate crystalline forms.
- Organic patterns.
- Subtle reflections.
IMPORTANT:
Do not use generic AI-generated-looking illustrations.
The visuals should feel art-directed, intentional and consistent with the brand.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
07. DISCOVERY EXPERIENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Create a premium discovery section.
Title:
"Explore what's possible."
Organize content into elegant categories:
- Scripts
- Visual Effects
- 3D Models
- Development Tools
Each category should have its own visual identity.
Create sophisticated resource cards containing:
- Preview image.
- Resource name.
- Short description.
- Creator name.
- Category.
- Relevant metadata.
- Price or free label, where applicable.
Cards should have subtle hover interactions.
Avoid the typical marketplace appearance.
Think editorial presentation mixed with premium product discovery.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
08. FEATURED CONTENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Create a featured resources section.
It should feel curated rather than automatically generated.
Use larger editorial cards with beautiful compositions.
Include:
- Featured scripts.
- Exceptional VFX.
- Premium 3D assets.
- Community creations.
The layout should have visual rhythm.
Do not make every card identical in size and composition.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
09. INTERACTIONS AND ANIMATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Animations must feel deliberate and extremely smooth.
Implement:
- Smooth page transitions.
- Elegant hover states.
- Subtle button interactions.
- Scroll-based reveals.
- Gentle floating animations.
- Sophisticated modal transitions.
- Smooth theme switching.
- Refined loading states.
Use Framer Motion where appropriate.
Avoid excessive animations.
Performance is a priority.
The website should feel responsive and fluid.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. RESPONSIVENESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The website must be fully responsive.
Desktop:
Use generous whitespace and sophisticated layouts.
Tablet:
Adapt navigation and card arrangements naturally.
Mobile:
Create a carefully designed mobile experience.
Do not simply shrink the desktop layout.
Every breakpoint must feel intentionally designed.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. TECHNICAL QUALITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Use:
- React.
- TypeScript.
- Tailwind CSS.
- Framer Motion.
- Lucide icons.
Maintain clean component architecture.
Create reusable components.
Use consistent spacing, typography and design tokens.
Ensure accessibility and good performance.
Avoid unnecessary dependencies.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
12. DESIGN RESTRICTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
These restrictions are extremely important.
DO NOT:
- Create a generic SaaS landing page.
- Use the typical purple/blue AI gradient aesthetic.
- Overuse rounded cards.
- Use excessive glassmorphism.
- Fill every section with unnecessary content.
- Use generic stock illustrations.
- Use random decorative blobs.
- Make the interface look like a premade dashboard.
- Use emojis as interface icons.
- Create inconsistent spacing.
- Use excessive shadows.
DO NOT sacrifice visual quality for quantity.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
13. FINAL DESIGN OBJECTIVE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The final result should feel like a premium creative technology brand.
Imagine if Apple designed a platform specifically for Roblox developers.
Ágata should communicate:
- Creativity.
- Precision.
- Quality.
- Sophistication.
- Innovation.
- Trust.
The experience should be visually memorable.
Pay extraordinary attention to small details:
spacing, alignment, typography, contrast, transitions, borders, shadows and proportions.
I want the result to look professionally art-directed, not automatically assembled.
Build the complete frontend experience with realistic placeholder content and polished interactions.
Prioritize design excellence above everything else.
